# Calculadora de Horas

### Função
&nbsp;&nbsp;&nbsp; O objetivo é calcular as horas e converter o valor á ser pago.

### Onde usar
&nbsp;&nbsp;&nbsp; Ideal para quem faz freelance e recebe por horas trabalhas ou para quem quer conferir se esta sendo pago corretamente para quem recebe por hora.
